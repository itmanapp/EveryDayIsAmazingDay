# ADR-003：台股除權息採官方 TWT49U 完整還原，修正報告結論

- 狀態：accepted
- 日期：2026-09-24
- 關聯 Spec／AC／Task：AC-034；TASK-015

## 背景

報告第 7.4 節指出除權息必須處理，否則除權息跳空會被偵測器誤判為「向下跌破」，並宣稱 TWSE 的除權息端點 `TWT49U` **四種參數組合全部失敗**（西元／民國、單月／區間），「目前沒有確認可用的官方除權息資料來源」，因此建議採方案 A（事件排除）並以方案 C（跳空偵測）保底。

2026-09-24 本次實測重跑了該端點，發現失敗原因是**參數名錯誤**，不是端點不可用：

| 請求 | 結果 |
| --- | --- |
| `TWT49U?response=json&strDate=20240101&endDate=20240131` | `{"stat":"查詢結束日期小於查詢開始日期，請重新查詢!"}`（誤導性錯誤） |
| `TWT49U?response=json&date=20240101` | `stat=OK` 但**忽略參數**，只回當日（115年09月29日）2 筆 |
| `TWT49U?response=json&startDate=20240701&endDate=20240731` | **`stat=OK`、449 筆、`113年07月01日 至 113年07月31日`**，欄位含除權息前收盤價、除權息參考價、權值+息值、權/息 |

存證：`docs/workflow/evidence/twse-probe/twse-endpoints.json`。同一批實測也確認 `holidaySchedule`（115 年市場開休市日期，27 筆）、`STOCK_DAY`（2330，2024-07，21 筆）、`STOCK_DAY_ALL`（1,380 筆）與 `t187ap03_L`（1,095 筆）皆可用。

## 選項與取捨

| 選項 | 優點 | 代價 |
| --- | --- | --- |
| 方案 A：只在除權息日附近排除 K 線 | 實作最簡單；已足夠擋掉主要風險 | 排除會讓序列出現缺口，規律的「連續根數」語意被破壞；浪費已可取得的權值資訊 |
| **方案 B：以官方權值+息值完整還原（採用為主）** | 序列連續、語意一致；所有既有演算法不需特例 | 需處理多次除權息與日期對齊；依賴 TWSE 端點的穩定性 |
| 方案 C：跳空偵測（保底） | 零依賴、能擋未知來源的跳空 | 啟發式、可能誤擋真實跳空 |
| 維持報告結論（無可用來源） | 不需新工作 | 與實測不符；放棄官方可用資料 |

## 決策

採**方案 B 為主、方案 A 為輔、方案 C 為保底**：

1. 以 `TWT49U?startDate=&endDate=` 取得事件（除權息前收盤價、除權息參考價、權值+息值、權/息），據以還原序列。
2. 還原失敗或事件缺漏時，在系統狀態標記並對受影響日期套用方案 A（標記不可用於判定）。
3. 保留方案 C 的跳空偵測作為未知來源的保底。
4. 驗證方式為 AC-034：還原後除權息日不產生假跌破命中，且未還原序列會產生假命中作為對照。

同時修正報告第 7.4 節與附錄 A／B 的敘述，並在 `docs/workflow/PROJECT.md` 的實測表記錄正確參數。

## 後果與調整條件

- 接受代價：`markets/adjust.py` 需處理民國年日期、除權息參考價與多次事件的疊加還原；需以 449 筆實測樣本作固定測試資料。
- 接受代價：與報告文字不一致；以本 ADR 與實測存證為準，並在交付報告標明修正。
- 風險：TWSE 端點參數若再變動（`startDate`／`endDate` 失效）→ 回到方案 A ＋ C，並以同一存證比對差異；若端點結構變更，需更新解析與樣本。
- 重訪條件：若需要上櫃（TPEx）或其他市場的除權息資料，另立 ADR。
