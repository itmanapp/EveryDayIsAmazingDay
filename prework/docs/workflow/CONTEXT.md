# 領域詞彙

僅記錄領域概念與關係，不在此放測試結果、實作計畫或完整 Spec。需求與架構的權威來源是 `docs/architecture/ENGINEERING-REPORT.md` 第 2 章；本檔只收斂本專案會用到的名詞，一個術語只保留一個定義。

## 市場與資料

| 詞彙 | 明確定義 | 容易混淆但不同的概念 |
| --- | --- | --- |
| K 線（candle） | 一段固定時間區間的價格摘要，含 open／high／low／close／volume 五個欄位，合稱 OHLCV | 不是「一天的價格」；週期不同則同一段歷史的根數不同 |
| 週期（interval） | K 線的時間粒度，本專案支援 `1m`、`5m`、`15m`、`1h`、`4h`、`1d`；**可用清單依來源而定**（TWSE 只有 `1d`） | 不是「資料筆數」；也不是所有來源都支援同一組週期 |
| 序列（Series） | pandas DataFrame，欄位固定且順序固定為 time／open／high／low／close／volume，`time` 為 UTC `datetime64[ns]`、升冪、無重複 | 不是任意 DataFrame；`ns` 解析度是契約的一部分（F-001 的根因） |
| 資料來源（Source） | 一組可查詢商品並取得 OHLCV 的實作，具有 `id`、`display_name`、`supported_intervals`、`needs_api_key`、`search`、`fetch` | 不是「檔案路徑」；快取是來源內部的行為，不是另一個來源 |
| 快取（cache） | 來源為避免重複請求而寫入本地的 K 線檔；有效時不發出請求 | 不是資料庫；快取過期且取得失敗時可回退使用（`cache-stale`） |
| 商品目錄（catalog） | 帶版本的來源與商品清單（代號、名稱、所屬來源、支援週期），可由更新攜帶 | 不是「監控清單」；目錄是可更新的字典，監控清單是使用者選的訂閱 |
| 交易日曆（calendar） | 某市場的開休市日期；用來判斷 K 線是否等距、標記非交易日 | 不是「時區」；股票市場的「連續等距 K 線」假設不成立 |
| 除權息（ex-rights／ex-dividend） | 公司配發股利或股票造成價格跳空的事件；需以權值+息值還原，否則跳空會被誤判為向下跌破 | 不是「一般下跌」；未還原的價格序列會產生假訊號 |
| 民國年 | TWSE 回應使用的年份格式（如 `113年07月01日` = 2024-07-01） | 不是西元；必須轉換後才能比較日期 |

## 演算法

| 詞彙 | 明確定義 | 容易混淆但不同的概念 |
| --- | --- | --- |
| ATR（平均真實區間） | 真實區間 TR 的 rolling 平均；`TR[i] = max(high-low, \|high-prev_close\|, \|low-prev_close\|)`，`ATR[i]` 只使用索引 i（含）以前的資料 | 不是 `high - low` 的平均；「不引用未來」是硬性要求 |
| 區間帶寬（band） | 盤整區間內最高 high 與最低 low 的差距 | 不是 ATR；band 是單一區間的實測高度，ATR 是滾動波動尺度 |
| 特徵向量（feature vector） | 一個視窗壓縮成的 10 維數字（方向、波動、K 線內部結構、量能、相對位置），全部為比值或正規化量 | 不是「價格序列」；也不是「規律參數」 |
| 尺度不變（scale invariance） | 整段價格同乘正數或加常數後，判定結果與命中位置完全不變 | 不是「正規化」的同義詞；本專案要求的是嚴格的判定不變性 |
| 視窗（window） | 從序列切出、長度固定為 W 的連續 K 線區間 | 不是「盤整區間」；盤整區間是規律內的一個相位 |
| 候選池（pool） | 拿來比對的所有視窗集合；步長 1 時長度 L 的序列產生 `L - W + 1` 個候選 | 不是「命中結果」 |
| 相似度分數 | 由加權 L1 特徵距離轉換而來，`分數 = 1 / (1 + 距離)`，值域 (0, 1] | 不是機率；也不是信心值 |
| 重疊抑制（overlap suppression） | 兩個候選片段的時間重疊比例超過門檻（預設 50%）時只保留分數較高者；恰好等於門檻者保留 | 不是「提醒去重」；前者處理同一段行情被多個視窗命中，後者處理同一事件被多輪輪詢重複命中 |
| 相位（phase） | 規律內部的連續段落：盤整（range）、跌破（breakdown）、回歸（recovery），各以索引表示 | 不是「K 線」；一個相位可包含多根 K 線 |
| 規律（pattern） | 一段可命名的價格行為結構；第一號具名規律為 `range_fakeout_reversion`（區間盤整 → 向下跌破 → 快速回到區間均值） | 不是「相似片段」；規律是布林判定，相似片段是連續分數 |
| 規律規格（PatternSpec） | 一組可序列化的相對門檻，全部是根數、倍數或具名目標，**不含任何價格欄位** | 不是「監控清單」；規格是規律的參數，監控清單是商品的訂閱 |
| 規律事件（PatternEvent） | 一次命中，含四個相位索引、confidence、實測 band、跌破深度與回歸根數 | 不是「提醒」；事件是偵測結果，提醒是輸出與去重後的行為 |
| 信心值（confidence） | 三個條件（帶寬、深度、回歸速度）滿足度的平均，0～1 | **不是機率**，只用來排序與篩選 |
| 後續走勢（forward path）／horizon | 命中片段結束後緊接的 H 根 K 線；`end + H` 超出序列者排除 | 不是「預測」；本專案只提供歷史統計 |
| 範例學習（learn） | 由一段數值範例推估可用的 `PatternSpec`，容差朝「更容易命中範例」放寬 | 不是「模型訓練」；沒有隨機性、沒有權重 |

## 服務、授權與更新

| 詞彙 | 明確定義 | 容易混淆但不同的概念 |
| --- | --- | --- |
| 本機服務（service） | 只 bind `127.0.0.1:8787` 的 Python 程序，同時跑監控迴圈與網頁 | 不是雲端服務；不對外開放、不需認證與 HTTPS |
| 提醒（alert） | 命中事件經去重後的一次輸出：主控台／網頁摘要 ＋ JSONL 或 SQLite 事件 | 不是「事件」本身 |
| 提醒去重鍵（dedup key） | `(商品, 週期, 規律 ID, 事件開始時間)`；用時間而非索引，因不同輪詢的序列長度會改變 | 不是「重疊抑制」 |
| SSE（Server-Sent Events） | 服務對瀏覽器的單向即時推播；標準庫可實作 | 不是 WebSocket；本專案不需要雙向 |
| 密鑰（license key） | 使用者向作者申請的授權字串 | 不是「租約」；密鑰是申請憑據，租約是簽章後的憑證 |
| 租約（lease） | 有到期日與簽章的授權憑證，存在使用者電腦上，有效期內完全離線可用（30 天滾動） | 不是「密鑰」；也不是「訂閱狀態」 |
| 機器指紋（machine fingerprint） | 由 `/etc/machine-id` 等穩定來源算出的雜湊（sha256 前 16 碼），讓一張租約只在一台機器有效 | 不是「帳號」；不收集可識別個人資訊 |
| features | 租約內的功能清單（如 `["start","update"]`），用來分級「可啟動」與「可更新」 | 不是「版本號」 |
| 撤銷（revoke） | 作者在後端使某密鑰或指紋失效；使用者下次驗證即停止 | 不是「到期」；到期可自助重新申請，撤銷則被拒絕 |
| 更新 manifest | `GET /v1/latest` 回傳的靜態版本描述（版本、發佈日、說明、catalog 版本與網址、檔案雜湊） | 不是「安裝包」；本版只顯示不下載 |
| 時鐘篡改防護 | 系統時間早於簽章內 `issued_at` 或本地 `high_water` 時，強制線上驗證 | 不是「防止改時間」；只是提高門檻 |
