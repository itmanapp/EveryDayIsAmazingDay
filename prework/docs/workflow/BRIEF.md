## 問題與目標

- 目標使用者：一位在個人電腦上自行操作、不寫程式也不學指令的個人投資者；他在乎的是「我心中那個熟悉的型態，能不能自動幫我盯」。
- 現在的困難／做法：心中有一個型態（例如「區間盤整後假跌破又拉回」），但只能靠肉眼一檔一檔翻歷史線圖；無法同時盯多個商品；主觀判斷不穩定且不可重現；圖表縮放不同看起來就不一樣；也不確定這個型態過去出現後走勢如何。
- 期望成果與成功指標（可觀察）：
  1. 雙擊桌面圖示後 10 秒內看到網頁，網頁關掉服務仍在背景盯盤。
  2. 在網頁上不必輸入代號即可用下拉搜尋選到商品，並在幾秒內看到「這個參數在這檔商品會命中幾次」。
  3. 命中時收到提醒（網頁內、瀏覽器原生、或服務端桌面通知），且同一事件不重複提醒。
  4. 同一輸入與參數永遠得到相同結果（無隨機性）；價格乘常數或平移後命中位置完全不變。
  5. 歷史回看能列出相似片段排行與其後續 N 根的統計（上漲機率、報酬分佈），並明確標示樣本數。
  6. 授權有效期內完全離線可用；逾期未連線時停止服務並提示重新申請。

## 主要情境

1. **一鍵啟動與背景盯盤**：使用者雙擊桌面圖示 → 服務已在執行時只開瀏覽器，否則背景啟動服務、等就緒、開瀏覽器。關閉網頁後服務仍在輪詢；命中時以桌面通知提醒。
2. **調整規律參數並即時預覽**：在規律參數面板以白話調整（盤整最少／最多根數、帶寬上限、跌破深度範圍、回歸根數上限），畫面即時顯示「這檔商品會命中幾次」；滿意後才寫入設定。
3. **由範例學習**：使用者貼上或上傳一段滿意的走勢 CSV → 按「學習」→ 顯示推估出的規格與命中預覽。推估不出來時明確說明原因，不給隨意參數。
4. **歷史回看**：選商品與時間範圍 → 表單化的相似片段排行與後續統計，並可在 K 線圖上看到盤整／跌破／回歸三個相位標註。
5. **首次啟用與離線啟動**：輸入密鑰 → 線上換取 30 天簽章租約 → 之後每次啟動只做離線驗章（不連網）；每次開啟與每 24 小時順帶續租與檢查更新。
6. **反例（會影響設計）**：
   - 商品資料不足（少於最短盤整根數 + 1）：必須顯示「無法評估」，不可顯示成「已檢查、沒有命中」。
   - 單一商品來源失敗：其餘商品仍要正常提醒，失敗只記在系統狀態頁。
   - 設定檔損毀：不可覆蓋使用者原檔，要回報並保留原內容。
   - 系統時間被往回調：必須強制線上驗證，不能靠本地時間延長授權。
   - 台股除權息日：價格跳空不可被誤判為「向下跌破」。

## MVP 與不做的事

- 本版必須包含（使用者 2026-09-24 選擇「全部」）：
  - 報告第 3.1／4／5 章的核心引擎：序列載入、10 維尺度不變特徵、相似度排序、滑動掃描與重疊抑制、後續走勢統計、規律模型與偵測、範例學習、監控輪詢與提醒去重、提醒輸出、命令列。
  - 報告第 6 章 v0.3：Web 介面 G1–G11（一鍵啟動、優雅關閉、監控清單管理、規律參數面板即時預覽、範例學習、即時提醒、K 線圖三相位、歷史回看、系統狀態、版本頁、授權頁）、SQLite 落地、設定原子寫入、三管道通知。
  - 報告第 7 章多市場：Source 介面與 registry、Binance、TWSE（含除權息還原與交易日曆）、Twelve Data、自訂 CSV、版本化 catalog。
  - 授權與更新：簽章租約、純 Python Ed25519 驗章、機器指紋、續期與到期停止、撤銷、功能分級、時鐘篡改防護、更新檢查六約束。
  - Cloudflare 後端：`/v1/activate`、`/v1/renew`、`/v1/latest`、`/catalog.json`、D1 資料表、後台操作、公開重新申請頁。
- 不在本版範圍（報告第 3.3 節「明確不做」＋本專案限制）：
  - 圖片解析（截圖不進入程式）、模型訓練、趨勢方向標籤與價格預測、自動下單、區網或網際網路存取本機服務、自動下載安裝更新、Yahoo Finance、規律參數加密發放。
  - 對外動作：`git push`、開 Issue、合併、部署 Cloudflare Worker、發布版本。
  - 真實 Cloudflare 帳號／D1／網域的連線驗證；macOS 與 Windows 的實機通知驗證。
- 平台／技術／時間／資料限制：Linux（Wayland，Chrome 為預設瀏覽器）；無 sudo、無預裝 pip；執行期依賴僅 numpy 與 pandas；服務只 bind `127.0.0.1`；所有自動測試必須離線可跑。

## 需求摘要

要做一套**完全在本機執行的市場規律偵測與監控提醒工具**，並附一套只負責版本記錄與授權的 Cloudflare 後端。核心是「把型態形式化成相對門檻，在序列上滑動掃描」：所有門檻使用 ATR 倍數、band 倍數與 K 線根數等相對單位，因此對價格量級與圖表縮放不變。產品提供兩條獨立路線：**相似度路線**（找出「差不多」的片段，輸出連續分數與排行）與**規律路線**（判斷「符不符合規則」，輸出布林命中、三個相位索引與信心值）。使用者介面為本機網頁（`127.0.0.1:8787`），資料來源可為 Binance、TWSE、Twelve Data 或自訂 CSV，並以簽章租約控制授權與更新。明確不做圖片解析、預測、下單與自動更新安裝。
